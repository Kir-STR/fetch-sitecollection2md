# Architectural invariants — инварианты проекта

Источник правды — спека `docs/superpowers/specs/2026-09-25-fetch-sitecollection2md-design.md`.

- `fetch.js` — только CLI: аргументы, загрузка адаптера, коды выхода.
- `lib/` — ядро, общее для всех коллекций: без знания о конкретных сайтах, зависимости только `node:*`.
- `adapters/<collection>.js` — всё, что специфично для сайта. В сеть — только через `ctx.get` (повторы и пауза уже там); не импортирует `lib/*` и другие адаптеры.
- `source`, итоговая дедупликация по `url` и запись снимка — в ядре; повторы при обходе источника адаптер может убирать сам.
- `test/fixtures/` — реальные ответы источников, не подделываются.
